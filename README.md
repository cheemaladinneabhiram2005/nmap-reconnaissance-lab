# Nmap Reconnaissance Lab

## Project Overview

This project demonstrates authorized network reconnaissance using Nmap on Kali Linux in a controlled lab environment.

The objective is to discover active hosts, identify open ports, detect running services, examine service-version information, and document potential security risks.

## Objectives

* Understand host discovery.
* Perform TCP port scanning.
* Identify services and versions.
* Explore banner and service enumeration.
* Use selected Nmap Scripting Engine scripts.
* Document observations and recommend security improvements.

## Tools and Technologies

* Kali Linux
* Nmap
* Nmap Scripting Engine (NSE)
* Linux terminal

## Methodology

1. Prepare the lab environment.
2. Identify the authorized assessment scope.
3. Perform host discovery.
4. Scan open ports.
5. Detect service versions.
6. Review appropriate NSE script output.
7. Document findings and limitations.
8. Recommend security improvements.

## Security and Ethics

All scanning must be limited to systems owned by the tester or explicitly authorized for assessment.

This project is intended for defensive security education and authorized testing.

## Learning Outcomes

* Improved understanding of network reconnaissance.
* Familiarity with Nmap commands and scan output.
* Practical experience documenting service exposure.
* Experience preparing security findings and recommendations.
